axSquiggle: how to use it

Sketch a screen the way you would on paper. It cleans itself up, sizes itself, and keeps an outline you can type into. Everything below is a looping demo: use Replay to watch one again.

1 Sketch2 Tap and type3 Keys4 Parts5 Work with your AI6 Run it

1Sketch it, it cleans itself up

Draw with the mouse, a pen or your finger. When you let go, the stroke becomes a real wireframe shape.

A box becomes a button. A scribble becomes text lines. A line with a hook becomes an arrow. A circle is a radio button or an avatar.

2Tap and type: radios, checkboxes, buttons in seconds

Tap an empty spot and type / to see every stamp. Type a label and press Enter: the next one appears underneath. Enter on an empty one ends the list.

Two or more radios or checkboxes get a border that always hugs them. A label can have several lines; indent a later line to make a smaller sub-label.

3You never have to remember a key

Press Space (or Ctrl+K) and every shortcut, / stamp and saved part is listed. Press the key you want and it runs; press Tab or / to search instead. Every toolbar button also shows its key, and a bar above the canvas lists the keys that work right now.

Handy: F Flow (draw, type, select and move without switching), Ctrl+C/X/V/D copy, cut, paste, duplicate, / search every frame.

4Parts: save once, stamp anywhere

A part is a group of elements saved under a name: a nav bar, a form row, a set of options. Select them, press B, name it. Then tap the canvas and type /your-name. The Parts tab lists them, and has three ready-made examples to try (/nav-bar, /form-row, /choice-group).

Parts are saved with the board, so they travel with it. Label text, container contents and wired arrows all come along.

5Work with your AI

Your AI (Claude Code, Claude Desktop, anything that speaks MCP) drafts the first screens. You edit them and write review notes: just select an element, or tap it in Review mode, and type. Then tell the AI to look.

The AI only ever sees your notes when it asks (get_review). Its edits arrive as one undoable change, and each note shows its reply.

6Run it anywhere

No account, no server needed for the app itself.

Just the app

Download axsquiggle.html and double-click it. One file, works offline.

App + AI

Run the single file (Node 18+, no install):

node axsquiggle.mjs

Open the address it prints; the app is already connected.

In your AI client

Add it as an MCP server:

claude mcp add axsquiggle -- node /path/to/axsquiggle.mjs
Press Space in the app any time to see every shortcut.
